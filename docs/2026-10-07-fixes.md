# Исправления сообщений, AI Study и PDF reader

Цвета, шрифты и визуальный стиль сохранены. Изменены поведение и конструкция.

## Применение миграций

Для существующего проекта применить **только новые** миграции, по порядку:

1. `supabase/migrations/202610070001_message_avatars.sql`
2. `supabase/migrations/202610070002_unverified_account_cleanup.sql`

Те же две миграции собраны в `supabase/releases/20261007_fixes.sql` для SQL Editor.
Использовать либо отдельные миграции, либо объединённый файл. Повторный запуск новых миграций безопасен для уже установленных функций и политики; данные не удаляются при установке. Применить перед
развёртыванием приложения, использующего новый RPC `dm_inbox_v2`.

Архив `artifacts/nis-hub-all-migrations-20261007.zip` содержит `schema.sql`, **все**
миграции репозитория и этот документ. Для пустой базы сначала выполнить
`schema.sql`, затем файлы `migrations/` в порядке имени. Для существующей базы
не повторять уже применённые миграции. История: `supabase_migrations.schema_migrations`.

## Неподтверждённые регистрации

Задача `nis-cleanup-unverified-accounts` запускается каждый час, на 17-й минуте.
Удаляет до 500 email-регистраций старше 72 часов, если email/телефон не подтверждены,
вход ещё не выполнялся и аккаунт не анонимный. Администраторы и OAuth-регистрации
сохраняются. Профиль и связанные строки с `ON DELETE CASCADE` удаляются вместе
с аккаунтом. Ошибка внешнего ключа у одного аккаунта не останавливает пакет.
Например, владельцу сохранённых файлов потребуется отдельно обработать Storage:
[Supabase запрещает удалять владельцев объектов](https://supabase.com/docs/guides/auth/managing-user-data#deleting-users).

Миграция включает `pg_cron`, когда расширение доступно. Если SQL Editor сообщает
`pg_cron unavailable`, включить [Supabase Cron](https://supabase.com/docs/guides/cron/install)
и выполнить:

```sql
select cron.schedule('nis-cleanup-unverified-accounts', '17 * * * *',
  'select private.cleanup_unverified_accounts();');
```

Проверка установки (не удаляет пользователей):

```sql
select jobname, schedule, active from cron.job
where jobname='nis-cleanup-unverified-accounts';
```

Обработка выполняется внутри Postgres без выгрузки списка пользователей или
HTTP-запросов. Функция недоступна `anon` и `authenticated`.

## Egress

- Аватарки: приватные WebP до 256 KiB, без открытия бакета. Только доступные
  участники видимого личного чата; блокировка закрывает выдачу новых URL.
- URL подписываются одним пакетным запросом, живут 10 минут и повторно
  используются сервером до 9 минут. Обновление профиля меняет ключ кэша.
  Изображения загружаются лениво, одинаковый URL в списке и заголовке позволяет
  браузеру использовать свой кэш. Уже выданная ссылка действует до истечения TTL.
- PDF загружается при открытии reader. Масштабирование, переходы и AI Study
  используют тот же документ. Каталог и чат не скачивают PDF.
- AI читает только выбранные строки `book_pages`, максимум 10 страниц и 30 000
  символов. Проверка готовности читает только статус и ревизию извлечения.
  Автоматические повторные запросы к Gemini не добавлены.

Браузерные проверки считают запросы: масштабирование и AI не должны повторно
получать PDF или обращаться к маршруту выдачи ссылки. Реальные показатели
Supabase нужно смотреть после выкладки; доступ к production базе не использован.

## Node.js и AI Study

Использовать Node 24 LTS (`.nvmrc`, `.node-version`, CI); нижняя совместимая
версия Node 22 — 22.13, согласно установленному `pdfjs-dist`. Тесты SQL выполняются
с ограниченной параллельностью, чтобы несколько WASM-баз не занимали всю память.

AI Study требует серверных `GEMINI_API_KEY`, `GEMINI_MODEL`, `AI_STUDY_ENABLED=true`
и актуального извлечённого текста из редактора книги. Исправлены диапазон при
изменении начальной страницы, следование текущей странице reader до ручного
выбора, размещение полей и сообщения об отсутствии подготовленного текста.
Старая конфликтующая flex-разметка удалена: AI занимает отдельную колонку на
компьютере и модальное окно на телефоне. Fullscreen reader использует существующую
разметку во весь экран и при отсутствии нативного Fullscreen API.
Для длительного запроса reader задаёт `maxDuration=90` (в пределах возможностей
хостинга). Реальный вызов Gemini с production ключом не выполнялся.

## Проверки

```sh
nvm use
npm ci
npm run typecheck
npm run lint
npm test
npm run build
node --import tsx tests/requested-fixes.browser.ts
```

SQL-тесты выполняют настоящие миграции в PGlite: доступ к аватаркам, блокировки,
скрытые чаты, автор последнего сообщения, удаление неподтверждённых регистраций,
каскад профилей и ограничения доступа. Планировщик pg_cron проверяется после
применения в Supabase; PGlite его не предоставляет.

Браузерный сценарий использует локальный оригинальный PDF и тестовые ответы,
проверяет Chromium/WebKit при ширине 390 и 1440 px: ширину reader, центрирование
масштаба, боковую колонку AI на компьютере, диапазон AI, отсутствие повторной загрузки PDF, аватарки и авторство
сообщений, отсутствие ложного «печатает» и поддержку reduced motion.

Проверка Chromium выполнена при обеих ширинах; существующий сценарий сохранения
маркеров, виртуализации и перезагрузки PDF также проходит. WebKit в этой среде
не запускается из-за отсутствующей `libicudata.so.74`; проверка Safari остаётся
неподтверждённой. Для запуска только установленного движка:
`NIS_BROWSER_ENGINES=chromium node --import tsx tests/requested-fixes.browser.ts`.
