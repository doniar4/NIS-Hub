# NIS Library Design System

## Design direction
Minimal, academic, editorial, precise, calm, modern.

The site should feel like a serious school product, not a generic AI startup.

## Avoid
- purple gradients
- neon gradients
- glassmorphism
- oversized rounded cards
- excessive shadows
- giant hero sections
- decorative 3D objects
- AI-generated photography
- fake testimonials
- fake statistics
- excessive motion
- cursor animations
- emoji as the main icon system

## Color approach
Use a neutral background, dark primary text, muted secondary text, subtle borders, and one restrained accent color.

Do not hard-code a large palette.

All important text must meet an appropriate WCAG contrast level.

## Shape
Use small, consistent corner radii. Buttons should generally be rectangular with modest rounding, not capsules.

## Typography
Use one primary sans-serif family with a restrained hierarchy.
Recommended:
- Inter, or another high-quality system-compatible sans-serif.

Suggested scale:
- page title: 36–40px desktop
- section title: 24–28px
- card/title: 18–20px
- body: 16px
- secondary: 14px

Adjust responsively.

## Layout
Prioritize whitespace and hierarchy.
Use thin separators where useful.
Avoid decorative cards when a simple list is clearer.

## Icons
Use a consistent SVG icon library if needed.
Every icon-only control must have an accessible name.

## Motion
Only functional transitions.
Keep animations short and subtle.
Respect prefers-reduced-motion.

## Profile
The profile should take inspiration from the identity-focused feeling of services such as Letterboxd without copying its visual design or branding.

Top 4 should be visually important but not oversized.

Example:
Top 4
1. Physics
2. Mathematics
3. Informatics
4. History

## Mobile
Design mobile-first.
The primary navigation should remain usable on small screens.
The PDF reader must not overflow horizontally.
