# Legal / Privacy Pre-launch Checklist

This is an engineering checklist, not legal advice.

## Copyright
- [ ] Every book has a verified right/licence/permission for the intended distribution.
- [ ] Source and rights information are stored internally.
- [ ] Do not upload random PDFs found online.
- [ ] Do not assume school use equals permission for public web distribution.
- [ ] Have a process for copyright complaints and removal.

## Privacy
Before real users:
- [ ] Identify the operator of the service.
- [ ] Identify what personal data is collected.
- [ ] Collect only data necessary for the stated features.
- [ ] Document retention/deletion.
- [ ] Document third-party processors.
- [ ] Provide an appropriate privacy notice.
- [ ] Provide an account/data deletion process where applicable.
- [ ] Determine requirements for minors and parental/guardian consent with qualified legal advice.

## Cookies / tracking
- [ ] Inventory all cookies/local storage/tracking technologies.
- [ ] Remove unnecessary analytics/tracking from MVP.
- [ ] If non-essential tracking is introduced, determine whether consent is required.
- [ ] Update privacy/cookie notices accordingly.

## Third-party services
Inventory:
- Supabase
- Vercel
- authentication providers
- PDF viewer dependencies
- analytics, if any
- external fonts/CDNs, if any

For each:
- [ ] What data is sent?
- [ ] Why?
- [ ] Is it necessary?
- [ ] Is it documented?

## Forms
- [ ] Clear labels.
- [ ] Clear consent wording where consent is actually needed.
- [ ] Links to Privacy Policy and Terms.
- [ ] No pre-checked optional consent.
- [ ] Keyboard accessible.
- [ ] Errors understandable without color alone.

## Accessibility
- [ ] Keyboard navigation.
- [ ] Focus states.
- [ ] Contrast.
- [ ] Alt text.
- [ ] Semantic headings.
- [ ] Form labels.
- [ ] Reduced motion support.
- [ ] Mobile usability.

## Launch requirements
Do not call the product production-ready until:
- [ ] Custom domain connected.
- [ ] Favicon added.
- [ ] No builder watermark/"Made with AI" or similar branding.
- [ ] Privacy Policy published.
- [ ] Terms and Conditions published.
- [ ] Cookie requirements assessed.
- [ ] Copyright status checked.
- [ ] Security checks completed.
- [ ] Accessibility checks completed.
- [ ] Real content rights confirmed.
- [ ] Backup/recovery plan exists.

## Refund policy
For a free MVP with no payments, do not create a fake refund process.
If paid functionality is introduced later, add a refund policy appropriate to the actual payment model and applicable law.
