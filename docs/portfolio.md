# Portfolio Evidence Plan

The project should produce evidence of genuine engineering work.

Keep:
- Git commit history
- architecture decisions
- database schema
- screenshots of early and final versions
- accessibility test results
- performance results
- security/RLS decisions
- copyright/content-rights process
- user testing notes
- feedback and iterations
- deployment history

Potential portfolio framing after real completion:

Problem:
Students often need access to school learning materials and schedule information in one place.

Solution:
A student-centered digital learning platform combining an authorized digital library, personal study profile, and schedule view.

Engineering:
- full-stack web application
- relational database
- authentication
- protected file storage
- PDF/document viewing
- personalized profiles
- schedule data model
- role-based administration
- accessibility and privacy considerations

Do not state user numbers, adoption, school partnership, impact, or performance results until those facts have actually been measured.
