# NIS Library — Codex Development Package

This package is the source of truth for the first MVP of NIS Library.

## Product
NIS Library is a minimal, student-focused digital learning space for Nazarbayev Intellectual School students. The first version focuses on a useful digital library and a lightweight student identity/profile.

## MVP goal
A student can:
1. Open the site.
2. Choose or configure their class.
3. Browse books by subject.
4. Open a book in a PDF reader.
5. Bookmark a book/page.
6. Create a profile.
7. Upload an avatar.
8. Select four favorite subjects as their Top 4.
9. View a schedule page using locally stored/test schedule data.

The schedule integration with the school's EduPage site is NOT part of the first implementation unless the integration method is verified and legally/technically appropriate.

## Important
Do not invent books, users, statistics, reviews, testimonials, school partnerships, or claims.
Do not scrape or republish copyrighted textbooks without confirmed permission.
Use test/sample documents until content rights are confirmed.
